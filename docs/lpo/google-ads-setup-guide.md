# Google Ads セットアップ操作ガイド

> **作成日**: 2026-04-07
> **前提ドキュメント**: `docs/lpo/google-ads-operation-plan.md`（v5: レビュー反映）
> **目的**: Google Adsアカウントの作成から広告出稿までの全手順を、画面操作レベルで案内する

---

## ステップ1: Google Adsアカウントの作成

### 1-1. アカウント作成

1. https://ads.google.com/ にアクセス
2. Googleアカウントでログイン（GA4と同じアカウントを推奨）
3. 「新しいGoogle広告アカウント」をクリック
4. **セットアップウィザードが表示されたら**:
   - 「キャンペーンの作成をスキップ」を選択（後で手動作成するため）
   - または、作成されたキャンペーンを**一時停止**する
5. ビジネス情報（名前・請求先住所・支払い方法）を入力して完了

> [!WARNING]
> セットアップウィザードの「スマートキャンペーン」は使わないこと。必ず「エキスパートモード」で操作する。スマートモードの場合は画面下部の「エキスパートモードに切り替える」をクリック。

### 1-2. エキスパートモードの確認

- 画面右上の **歯車アイコン（管理）** → 「エキスパートモードに切り替える」
- すでにエキスパートモードなら、左メニューに「キャンペーン」「広告グループ」「キーワード」等が表示される

---

## ステップ2: Auto-tagging（自動タグ設定）の有効化

1. Google Ads 画面左メニュー → **「管理」** → **「アカウント設定」**
2. 「自動タグ設定」のセクションを見つける
3. **「ユーザーが広告をクリックするとアクセスしたURLにタグを追加する」** にチェックを入れる
4. **「保存」** をクリック

> [!IMPORTANT]
> Auto-tagging は GA4 との正確なデータ連携に必須。これがOFFだと、広告経由のCVがGA4で正しく計測されない。

---

## ステップ3: GA4 と Google Ads をリンクする

### 3-1. GA4側の操作

1. [GA4管理画面](https://analytics.google.com/) にアクセス
2. 左下の **歯車アイコン（管理）** をクリック
3. プロパティ列 → **「Google Adsのリンク」** をクリック
4. **「リンク」** ボタンをクリック
5. 「Google Adsアカウントを選択」→ ステップ1で作成したアカウントを選択
6. 「パーソナライズド広告を有効にする」→ **ON**
7. **「送信」** をクリック

### 3-2. 確認

- リンク一覧にGoogle Adsアカウントが表示されればOK
- リンクが反映されるまで最大24時間かかる場合がある

---

## ステップ4: コンバージョンのインポート

### 4-1. GA4のコンバージョンをGoogle Adsにインポート

1. Google Ads → 左メニュー **「目標」** → **「コンバージョン」** → **「概要」**
2. **「+ 新しいコンバージョンアクション」** をクリック
3. **「インポート」** を選択
4. **「Google アナリティクス 4 プロパティ」** を選択 → **「続行」**
5. GA4のイベント一覧から以下を選択:

| イベント名 | 設定 |
|---|---|
| `generate_lead` | ✅ チェック → **Primary** に設定 |
| `form_start` | ✅ チェック → **Secondary** に設定 |
| `step1_complete` | ✅ チェック → **Secondary** に設定 |
| `step2_complete` | ✅ チェック → **Secondary** に設定 |

6. **「インポートして続行」** をクリック

### 4-2. Primary / Secondary の設定確認

1. Google Ads → 目標 → コンバージョン → 概要
2. `generate_lead` をクリック → **「設定を編集」**
3. 「目標と最適化」セクション:
   - **主な目標に使用する**: ON（= Primary）
4. 他の3つのイベント（`form_start` / `step1_complete` / `step2_complete`）:
   - **主な目標に使用する**: OFF（= Secondary / 観測用）

## ステップ5: キャンペーンの作成

### 5-1. キャンペーン作成

1. Google Ads → 左メニュー **「キャンペーン」** → **「+」** → **「新しいキャンペーン」**
2. 目標: **「リード」**（見込み顧客の獲得）
3. キャンペーンタイプ: **「検索」**
4. 目標達成方法: 「ウェブサイトへのアクセス」→ URL: `https://rakuup.com/`

### 5-2. キャンペーン設定

| 項目 | 設定値 |
|---|---|
| キャンペーン名 | `Raku UP 検索_リード獲得` |
| 配信ネットワーク | **検索ネットワークのみ**（ディスプレイネットワークはOFF） |
| 配信地域 | **日本** |
| 地域オプション | **Presence（実際にその地域にいる人）** ※下記注意参照 |
| Search Partners | **OFF** ※初期の少額検証ではGoogle本体検索のみに絞る |
| 言語 | **日本語** |
| 入札戦略 | **Manual CPC（手動クリック単価）** |
| 日予算 | **¥1,700〜2,000**（初期はここから） |
| 配信開始日 | 設定したい日付 |
| 配信時間帯 | **終日**（初期、データ取得後に最適化） |

> [!WARNING]
> **ディスプレイネットワークは必ずOFFにする**。デフォルトでONになっていることがあるので注意。

> [!IMPORTANT]
> **地域オプションの変更手順**: キャンペーン設定 → 「地域」セクション → 「地域のオプション」 → **「その地域にいるユーザー」を選択**。デフォルトの「その地域にいるユーザー、またはその地域に関心を示したユーザー」のままだと、海外からの無駄クリックが入る可能性がある。

### 5-3. Campaign-Specific Goals の設定

1. キャンペーン設定画面の「目標」セクション
2. **「コンバージョンの目標を設定」** → **「キャンペーン固有の目標設定を使用」**
3. `generate_lead`（Primary）**のみ**を選択
4. 中間ステップ（`form_start` 等）は**選択しない**（Secondaryとして自動記録される）

## ステップ10: 配信前の最終チェック

- [ ] Auto-tagging が ON になっているか
- [ ] GA4 ↔ Google Ads のリンクが完了しているか
- [ ] `generate_lead` が Primary に設定されているか
- [ ] ディスプレイネットワークが OFF になっているか
- [ ] 地域オプションが **Presence（その地域にいるユーザー）** になっているか
- [ ] Search Partners が OFF になっているか
- [ ] 入札戦略が Manual CPC になっているか
- [ ] 日予算が ¥1,700〜2,000 に設定されているか
- [ ] AG2（課題訴求）が「一時停止」になっているか
- [ ] 除外キーワードリストがキャンペーンに適用されているか
- [ ] 広告文の Ad Strength が「Good」以上か
- [ ] ランディングページ URL が `https://rakuup.com/` になっているか

### テスト送信（CV計測の確認）

1. Google Adsでキャンペーンを有効化
2. 自分で対象キーワードを検索し、広告をクリック（※費用が発生するので注意）
3. LP上のフォームからテスト送信
4. GA4 → リアルタイム → `generate_lead` イベントが発火するか確認
5. 24〜48時間後に Google Ads → コンバージョン列に反映されるか確認

> [!NOTE]
> テスト送信の代替方法: GA4のDebugView（Preview mode）を使えば広告クリックなしでイベント発火を確認できる。ただし広告→GA4→Google Adsの完全なデータフローを確認するには、実際の広告クリックが最も確実。

## 配信開始後のルーティン

| 頻度 | やること |
|---|---|
| **毎日** | 検索クエリレポート確認 → 不要クエリを除外 |
| **3日ごと** | CPC・CTR・品質スコアのチェック |
| **週1回** | 広告文パフォーマンスレビュー |
| **月1回** | フルレビュー（KPI達成状況・予算・入札戦略の見直し） |
