# サイト公開チェックリスト

> 新規LP・サイトを公開する際に必ず確認する項目一覧。
> 今回の教訓（Google検索でサイト名が「Netlify」と表示された問題）を踏まえて作成。

---

## 1. 基本ファイル構成

- [ ] `index.html` がルート直下に存在する
- [ ] `robots.txt` が設置されている
- [ ] `sitemap.xml` が設置され、本番URLで記載されている
- [ ] `favicon.png`（または `.ico`）が設置されている

---

## 2. ファビコン・アイコン

- [ ] `<link rel="icon">` が全HTMLページの `<head>` に記述されている
- [ ] `<link rel="apple-touch-icon">` が設定されている
- [ ] ファビコン画像が正しいブランドロゴ／アイコンになっている
- [ ] ファビコンのサイズが適切（推奨: 48px以上の正方形 PNG、Google推奨は48×48の倍数）
- [ ] ファビコンのパスが正しく、404にならないことを確認

---

## 3. SEO メタタグ

- [ ] `<title>` タグにサービス名とページ内容が含まれている
- [ ] `<meta name="description">` が各ページに設定されている
- [ ] `<link rel="canonical">` が本番URLになっている
- [ ] 非公開ページ（thanks.html等）に `<meta name="robots" content="noindex">` がある

---

## 4. OGP（SNSシェア用）

- [ ] `og:title` / `og:description` / `og:image` / `og:url` が設定されている
- [ ] `og:image` が絶対URL（本番ドメイン）で指定されている
- [ ] OGP画像が推奨サイズ（1200×630px）以上で存在する
- [ ] `twitter:card` / `twitter:title` / `twitter:image` が設定されている
- [ ] [OGPデバッガー](https://developers.facebook.com/tools/debug/)等で表示確認

---

## 5. 構造化データ（JSON-LD）⚠️ 最重要

> **今回の教訓**: `WebSite` スキーマが未設定だと、Google検索結果のサイト名にホスティングサービス名（Netlify等）が表示される。

- [ ] **`WebSite` スキーマ** がトップページに設置されている
  ```json
  {
    "@type": "WebSite",
    "name": "サイト名",
    "url": "https://本番URL/"
  }
  ```
- [ ] `name` にサービス名 / ブランド名が正しく入っている
- [ ] `url` が本番URLになっている
- [ ] 必要に応じて `ProfessionalService` / `Organization` 等の追加スキーマがある
- [ ] [リッチリザルトテスト](https://search.google.com/test/rich-results) でエラーがないことを確認

---

## 6. Google Search Console

- [ ] Google Search Console にサイトを登録済み
- [ ] 所有権の確認が完了している
- [ ] `sitemap.xml` を Search Console に送信済み
- [ ] 公開後にトップページのインデックス登録をリクエスト

---

## 7. Google Analytics (GA4)

- [ ] GA4 の測定ID が正しいIDに設定されている（`G-XXXXXXXXXX` のままになっていないか）
- [ ] 全ページに GA4 タグが埋め込まれている
- [ ] GA4 リアルタイムレポートでアクセスが計測されることを確認

---

## 8. フォーム・機能確認

- [ ] お問い合わせフォームの送信テストが完了（本番APIキーで）
- [ ] サンクスページへの遷移が正常
- [ ] フォームの送信先メールアドレスが正しい
- [ ] バリデーション（必須項目、メール形式等）が動作する

---

## 9. 表示・デザイン確認

- [ ] PC（1920px, 1366px）で全セクション正常表示
- [ ] タブレット（768px）で表示崩れなし
- [ ] スマートフォン（375px, 390px）で表示崩れなし
- [ ] 全ての画像が表示される（404なし）
- [ ] 画像パスが相対パスで、大文字小文字が一致している
- [ ] リンク切れがない（内部リンク・外部リンク）

---

## 10. パフォーマンス・セキュリティ

- [ ] HTTPS が有効（証明書エラーなし）
- [ ] [PageSpeed Insights](https://pagespeed.web.dev/) でスコア確認（目標: 80以上）
- [ ] 画像が最適化されている（WebP対応、適切なサイズ）
- [ ] CSS/JS の minify版が使用されている（本番環境）

---

## 11. 法務・コンプライアンス

- [ ] プライバシーポリシーページが設置されている
- [ ] 特定商取引法に基づく表記が記載されている
- [ ] Cookie利用に関する説明がプライバシーポリシーに含まれている
- [ ] 著作権表記（© 20XX 会社名）が正しい年号になっている

---

## 12. 公開後フォローアップ

- [ ] Google Search Console でインデックス登録リクエスト
- [ ] 数日後に `site:ドメイン名` で検索し、正しいサイト名・ファビコンで表示されるか確認
- [ ] OGP画像がSNSシェア時に正しく表示されるか確認
- [ ] フォーム送信の通知メールが届くか再確認

---

## 補足: よくある失敗パターン

| 症状 | 原因 | 対策 |
|---|---|---|
| 検索結果のサイト名が「Netlify」 | `WebSite` 構造化データ未設定 | JSON-LDで`WebSite`スキーマを追加 |
| 検索結果のアイコンがデフォルト | ファビコン未設定 or サイズ不適切 | 48px以上の正方形PNGを設定 |
| SNSシェア時に画像が出ない | OGP画像パスが相対URL | 絶対URL（`https://...`）に修正 |
| GA4でデータが取れない | 測定IDが `G-XXXXXXXXXX` のまま | 正しいGA4測定IDに差し替え |
| フォーム送信が失敗 | テスト用APIキーのまま | 本番用APIキーに差し替え |
